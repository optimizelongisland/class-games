# Class Game Room

Classroom review games, grouped by subject and unit. Students open `index.html` and pick a game.

## Add a game
1. Put the game's HTML file in `games/` (one self-contained file per game).
2. Add `<a href="../index.html" class="cg-back" ...>` right after `<body>` so students can get back (copy the line from any existing game).
3. In `index.html`, add an entry to the `SUBJECTS` list under the right unit (or add a new unit or subject).

## Hosting
Published with GitHub Pages from the `main` branch root.
