One-time setup

Connect the live board

The student game works without this, but the board can't show anything until it is connected to a free Firebase database.

  1. Go to console.firebase.google.com, sign in with a Google account, and click Create a project (any name, Google Analytics off).
  2. In the left menu choose Build → Realtime Database → Create database, pick the United States location, and choose Start in test mode.
  3. Open the Rules tab, replace everything with {"rules":{"u5r2":{".read":true,".write":true}}}, and click Publish. (Test mode turns itself off after 30 days; this rule doesn't.)
  4. Copy the database URL at the top of the Data tab (it ends in firebaseio.com or firebasedatabase.app), paste it below and click Connect. Then send it to Claude so it gets built into the student game and the hint pages.

Only group numbers, team names and answers are stored. Ask groups not to type full names.
